
# 📱 Pokémon Card App - Frontend

Este é o aplicativo mobile do projeto de gerenciamento de Pokémons (CRUD), desenvolvido como atividade acadêmica. A interface consome uma API local para listar, cadastrar, editar e excluir os registros de Pokémons.

---

## 🛠️ Tecnologias Utilizadas

* **React Native** (com Expo)
* **Axios** (para comunicação HTTP com a API)
* **JavaScript**

---

## 🚀 Como Executar o Projeto

Para rodar o aplicativo na sua máquina local, siga os passos abaixo:

### 1. Pré-requisitos
Certifique-se de ter instalado em sua máquina:
* **Node.js** (versão 18 ou superior recomendada)
* **Expo Go** instalado no seu celular (se for testar em um dispositivo físico) ou um emulador configurado.
